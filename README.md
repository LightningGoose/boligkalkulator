# boligkalkulator

En enkel og interaktiv bolig- og lånekalkulator tilpasset det norske boligmarkedet.

Kalkulatoren lar deg beregne månedlige kostnader ved boligkjøp og sammenligne ulike kjøpesummer og finansieringsalternativer.

Funksjoner

Beregning av boliglån, renter og månedlige kostnader

Egenkapital, gave og privatlån

Beregning av gjeldsgrad og samlet gjeld

Sammenligning av ulike kjøpesummer og egenkapitalbeløp

Justerbare verdier og delbare beregninger

Teknologi

HTML, CSS og JavaScript. Ingen backend eller eksterne avhengigheter.

Bruk

Åpne index.html i nettleseren, eller bruk kalkulatoren på GitHub Pages.

Merk

Beregningene er veiledende og erstatter ikke en individuell vurdering fra banken.
